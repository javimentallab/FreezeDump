# Security policy

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately through GitHub: [Report a vulnerability](https://github.com/javimentallab/FreezeDump/security/advisories/new).

Say what you found, how to reproduce it and which version you used. English or Spanish are both fine.

This project has a single maintainer, so replies are best effort. I aim to answer within 14 days.

## What counts

Anything that exposes a memory dump, since a dump can hold passwords and other private data, and anything that lets another user run code through the installed task.

## Supported versions

Only the latest release gets security fixes.
